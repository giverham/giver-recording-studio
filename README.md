# Giver Recording Studio

Official website for **Giver Recording Studio** — recording, mixing, mastering, and original productions.

**Live site:** [giverrecords.com](https://www.giverrecords.com)

## For visitors

- Browse beats and productions  
- Book a session  
- Submit a track  
- Contact the studio  

## For the studio

The admin area is private. Sign in from the site when you need to update catalog, bookings, or messages.

## Local preview

```bash
npm install
npm run dev
```

Production settings stay on the hosting dashboard. Do not put live credentials in this repository.
